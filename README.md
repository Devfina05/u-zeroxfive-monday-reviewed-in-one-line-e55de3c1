# Monday, Reviewed in One Line

[![make.fun · u-zeroxfive-monday-reviewed-in-one-line-e55de3c1](https://make.fun/badge/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1.svg)](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)

One line (145 characters), the funniest one-line review of the entrant's own
Monday, written by a program to `/output/entry.txt`. Node 22, standard
library only.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```

## The review

> Monday showed up unannounced, ate all my motivation, left the dishes in the sink, and still expects five stars. One star. Would not Monday again.
